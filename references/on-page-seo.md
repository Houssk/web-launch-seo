## Every page

- **Title** present and unique. Google sets no length limit ("there's no limit on how long a `<title>` element can be") and truncates by display width: over about 60 characters is a warning, not an error. Source: https://developers.google.com/search/docs/appearance/title-link (read 2026-10-12)
- **Meta description** present and unique per page; no length limit either, about 50 to 160 characters is the usual snippet range (a convention). Source: https://developers.google.com/search/docs/appearance/snippet (read 2026-10-12)
- **Canonical**: one `<link rel="canonical">` per indexable page, absolute, the page's own URL on the public https host; never on the 404 page.
- **Open Graph**: `og:type`, `og:title`, `og:description`, `og:url` (equal to the canonical), `og:image` (absolute, 1200 x 630, file present), `og:site_name` (the entity name), `og:locale`. **Twitter**: `twitter:card` (`summary_large_image` with a real cover).
- **Headings**: one `<h1>`, logical `<h2>`/`<h3>`; `lang` on `<html>`. Question-style headings with a first sentence that answers help snippets and AI answers. Recommendation (unsourced).
- **No inline CSS** (`style="..."`): CSS in files or component styles keeps the CSP strict. Recommendation (unsourced).

`check-site`: META-001/002/003, CANON-001/002/003, OG-001.

## robots meta and sitemap

- `index, follow` on content pages; `noindex, follow` on legal and utility pages if wanted, and then out of the sitemap.
- The robots meta, `robots.txt` and the sitemap come from one indexing switch (see the pre-launch reference).
- Sitemap: absolute URLs; `lastmod` is used by Google only if it is consistently and verifiably accurate; `priority` and `changefreq` are ignored. Use the real modification date of each page, never the build date for all. Source: https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap (read 2026-10-12)
- Generated by the build (for Astro, `@astrojs/sitemap` produces `sitemap-index.xml`); `robots.txt` points to it.

`check-site`: SITEMAP-001 to SITEMAP-005, INDEX-001.

## Multilingual sites

- Typed dictionary: one source locale file, the others typed against it; a missing key fails the build. Recommendation (unsourced).
- Routing: default locale unprefixed (`/`), others prefixed (`/en/`).
- **hreflang per page**, not only on the home page: each page lists its translated equivalents, itself and `x-default`, with absolute URLs, and every alternate links back (HREFLANG-001).
- Pair translations explicitly (a `lang` field and a shared `translationKey` in the content schema); emit no alternate for an unpaired page rather than pointing it at a home page.
- **No automatic redirect by browser language**: Google advises against it; use hreflang and a language selector. Source: https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites (read 2026-10-12)
- Localise display taxonomy (category labels) in the UI and in JSON-LD `articleSection`.

## Internal links

Every internal link leads to a built page (LINK-001). Each new article links to one or two related articles, a resource and a call to action; update older articles to link to it.

## Say in the report

- Length warnings as conventions, not Google rules.
