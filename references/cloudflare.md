# Cloudflare zone settings

Load when the site is served by Cloudflare (Workers static assets or Pages) and the zone is being set up or reviewed. Another host does not need this file.

## Hardening checklist

Recommendation (unsourced): the settings below are the reference setup; check each one in the dashboard and online.

- [ ] SSL/TLS mode **Full (strict)**; **Always Use HTTPS** on (`curl -sI http://example.com/` answers 301 or 308, never 200).
- [ ] **HSTS** on, only once every subdomain works in HTTPS (it is hard to undo); start with a short `max-age`.
- [ ] Minimum TLS version 1.2.
- [ ] **www to apex**: DNS `www` proxied, plus a redirect rule `Hostname eq "www.example.com"` to `concat("https://example.com", http.request.uri.path)`, 301, query string preserved. Check with `curl -sI "https://www.example.com/a/?q=1"` (path and query kept).
- [ ] Security headers in `_headers` (see the security headers reference); remember that `_headers` does not reach responses generated by a Worker.
- [ ] Bots and AI crawlers: AI Crawl Control, managed robots.txt and Bot Fight Mode can override the repository's `robots.txt` (see the AI crawlers reference).

## Corrected claims

| Setting | What it really does |
| --- | --- |
| Tiered Cache | Reduces requests to an origin. Smart Tiered Cache Topology is available on all plans; Generic Global Tiered Topology is Enterprise only. A site served entirely by Workers static assets has no origin to protect: little to gain (a deduction, not a documented statement). Source: https://developers.cloudflare.com/cache/how-to/tiered-cache/ (read 2026-10-12) |
| Crawler Hints | Sends IndexNow signals based on cache MISS events; the page does not name the engines and does not mention sites served by Workers. Do not promise "automatic IndexNow pings to Bing": check that URLs arrive in the IndexNow report of Bing Webmaster Tools. Source: https://developers.cloudflare.com/cache/advanced-configuration/crawler-hints/ (read 2026-10-12) |
| Early Hints | Emits a 103 only when the response carries `Link` headers with `preload` or `preconnect`: no effect without them. Source: https://developers.cloudflare.com/cache/advanced-configuration/early-hints/ (read 2026-10-12) |
| Auto Minify | Deprecated on 2024-08-05 (deprecation date on the API deprecations page): minify at build time. Source: https://developers.cloudflare.com/fundamentals/api/reference/deprecations/ (read 2026-10-12) |
| Bot Fight Mode | Challenges detected bots, can challenge API traffic, cannot be bypassed with WAF custom rules. Off for a content site (Recommendation (unsourced)). Source: https://developers.cloudflare.com/bots/get-started/bot-fight-mode/ (read 2026-10-12) |

Already on by default on Cloudflare: HTTP/3, Brotli compression. Recommendation (unsourced): verify in the dashboard.
